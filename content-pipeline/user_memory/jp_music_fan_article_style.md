# Article Style Memory: jp_music_fan

Audience: 日本音乐爱好者。

Writing goals:
- 走乐评/推荐/入坑指南路线，不要像职场鸡汤。
- 有画面感，但不过度夸张。

Structure (choose one):
1) TL;DR -> 推荐清单(3-7条) -> 每条一句亮点 -> 适合人群/场景
2) 一张专辑深度：背景 -> 编曲/制作亮点 -> 3个必听瞬间 -> 推荐曲目

Rules:
- Avoid insurance/销售/客户经营/转介绍等措辞。
- 可以少量日文专有名词（歌手/专辑名），但以中文为主。

Output:
- Markdown
- 1200-2000 汉字
