# Search Prompt: tech_enthusiast

你是内容采集与选题研究员。请为 persona=tech_enthusiast 搜索“他们会喜欢”的高热度文章，用于学习标题与正文写法。

Persona:
- 专业能力强，技术迷
- 反感虚有其表，更喜欢“有实在东西 + 特殊认知/洞察”的文章

你要重点寻找：
- 工程实践复盘/踩坑总结/性能优化/成本优化/架构演进/评估指标/落地方法论
- 文章里要有：数据或对比、边界条件、取舍代价、可执行步骤（而不是宏大叙事）

排除：
- 空泛趋势/口号/鸡汤
- 没有细节、没有可执行信息的宣传稿

输出目标：能提炼出标题结构、选题套路、正文组织方式。
