# Search Prompt: tech_enthusiast

目标：采集“AI 工程化/落地实践”为主的高质量中文文章（少鸡汤、少泛趋势），用于学习标题与正文结构。

受众画像（tech_enthusiast）：
- 专业能力强，技术迷；反感虚有其表
- 偏好：有实在内容 + 边界条件/取舍代价 + 可执行细节 + 数据或对比
- 重点领域：大模型(LLM) / Agent / RAG / 工作流自动化 / vibe coding / AI 应用落地

优先采集的内容类型（尽量覆盖多个角度）：
- 落地复盘：从 0 到 1 上线、失败复盘、踩坑总结、指标回归
- 评估与对比：方案选型、评估指标、A/B、成本-效果权衡
- 工程化实践：提示词/工具调用/记忆、RAG 召回与质量、观测与调试、数据与迭代
- 性能与成本：延迟/吞吐、推理成本、缓存/批处理、降本增效

采集时更看重：
- 有具体场景/上下文（公司/业务/约束条件）
- 有明确结论 + 依据（数据、对比、案例、失败原因）
- 有可复用的方法（步骤、清单、注意事项）

明确排除：
- 纯宏观趋势、口号、鸡汤
- 课程广告/软文
- 只有概念没有细节（缺场景/缺数据/缺对比）

输出目标：能提炼出标题结构、选题套路、正文组织方式。
