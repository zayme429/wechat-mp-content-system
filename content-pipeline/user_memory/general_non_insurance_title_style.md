# Title Style Memory: general_non_insurance

Applies to all users EXCEPT insurance_agent.

Goal: clean, non-salesy titles.

Rules:
- Avoid insurance/销售/客户经营/转介绍/理赔/保单/代理人等措辞。
- Avoid“鸡汤/情绪化夸张/标题党”。
- Prefer concrete nouns and clear topics.
- Keep 16-32 Chinese characters when possible.

Output:
- Return ONLY the title, no quotes, no markdown.
