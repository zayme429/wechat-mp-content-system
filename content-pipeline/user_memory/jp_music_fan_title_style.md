# Title Style Memory: jp_music_fan

Audience: 日本音乐爱好者。

Goal: titles feel like a Japanese music fan / playlist curator.

Rules:
- Avoid insurance/销售/客户经营/转介绍等措辞。
- Prefer "作品/专辑/现场/编曲/声线/氛围/年代" 等词。
- Diversity: avoid repeating the same prefix ("探索/日本音乐/趋势") across many titles.
- Title patterns:
  - "如果你喜欢 X，这张/这首 Y 别错过"
  - "从 A 到 B：一条入坑路线"
  - "为什么这张专辑值得反复听"
- Length: 14-28 Chinese characters.

Output:
- Return ONLY the title, no quotes, no markdown.
- Do NOT prefix with "标题:" / "标题：".
